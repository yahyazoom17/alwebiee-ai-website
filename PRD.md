## 6. Interaction and Motion Design

Include:

- Responsive navigation.
- Subtle link and button transitions.
- Refined card hover states.
- Subtle reveal animations for selected sections.
- An optional interactive hero visualization.

Animation guidelines:

- Prefer CSS transitions and keyframes when sufficient.
- Use an existing animation library if it is already installed and suitable.

- Ensure the page remains usable when animation is disabled.

Every interactive element must have a meaningful behavior. Avoid decorative controls that appear clickable but do nothing.

## 12. Implementation Workflow

Follow this sequence:

Phase 1 — Inspect
Understand the existing codebase, dependencies, routes, and styling system.

Phase 2 — Design
Establish the design system, visual hierarchy, responsive strategy, and component architecture.

Phase 3 — Implement
Build the entire landing page, not just the hero. Implement the responsive layout, styling, content, visual assets, and interactions.

Phase 4 — Verify
Run the project's available lint, type-check, and build commands. Inspect package.json before choosing commands. Do not assume scripts exist.

Phase 5 — Fix
Resolve errors introduced by your changes. Check responsive issues, missing assets, hydration problems, accessibility concerns, and nonfunctional controls.

Phase 6 — Polish
Review the composition and spacing, improve weak sections, eliminate generic styling, and ensure the website feels like one cohesive brand.

Use available browser or visual inspection tools if they are already configured in the environment. Otherwise, run the application and use the available verification methods.

Do not claim to have visually inspected the site unless you actually did so.
